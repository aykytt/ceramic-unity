# Ceramic Factory — gizlilik politikası ve kullanım şartları

Google Play'in zorunlu tuttuğu gizlilik politikası ve kullanım şartları sayfası.
Tek dosya: `index.html`, GitHub Pages ile yayınlanıyor.

**Yayındaki adres:** https://aykytt.github.io/ceramic-unity/

Aynı adres iki yere giriyor:

1. **Play Console** > Uygulama içeriği > Gizlilik politikası
2. **Oyunun içi**: açılıştaki şartlar ekranının bağlantısı (`AcilisAkisi.sartlarUrl`)

## Uygulama

**Ceramic Factory** — Android için seramik atölyesi işletme oyunu
(`com.ceramicfactory.app`). Unity ile geliştiriliyor.

## Sayfanın bugünkü kapsamı

Uygulamanın bu sürümünde reklam ağı, analiz aracı ve izleme yazılımı bulunmuyor;
oyun ilerlemesi yalnızca cihazda saklanıyor. Metin bunu anlatıyor.

Reklam veya kullanım istatistiği eklendiğinde sayfa metni, Play Console veri
güvenliği formu ve uygulamadaki şartlar sürümü **birlikte** güncellenir.

## Güncelleme
